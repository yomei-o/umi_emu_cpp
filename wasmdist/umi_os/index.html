3次元の水 — MLS-MPM (C++ / WASM, GPU なし)

webgpu-ocean と同じ骨格を、GPU を使わず C++ だけで。
MLS-MPM：粒子は 3×3×3 の格子に質量と運動量を撒き（P2G）、格子で重力と壁を掛け、 また集め直す（G2P）。近傍探索が要らない O(N) なので CPU でも回ります。 水は応力が圧力だけなので stress = −dt·V·4/dx²·E·(J−1) のスカラーで済みます。
描画は画面空間の流体レンダリング：粒子を球として深度だけ撒き → その深度を narrow-range filter でならし → 深度から法線を復元 → 厚みで吸収（Beer-Lambert）→ フレネルで反射と屈折を混ぜる。水の青は色を塗ったのではなく、赤から先に吸われた結果です。
